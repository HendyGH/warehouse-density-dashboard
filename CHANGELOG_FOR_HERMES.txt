17. BUGFIX 27 July 2026 - "DEMAND PRESSURE BY BIN CATEGORY" WAS WRONG
    (src/index.html only, function buildZonePutawayPlan + zone card render)

    REPORTED SYMPTOMS (confirmed from a user screenshot):
      - Zone O2 showed NO category block at all, even though the zone has
        137 PACKING bins visible in the heatmap right below the card.
      - Zone O5 showed only RAW MATERIAL (175 bins). Its BATTERY block
        (112 bins, clearly visible in the heatmap) was missing.
        175 + 112 = 287 = the zone total, so a whole category vanished.
      - Category totals did not add up to the zone header numbers.

    ROOT CAUSE:
      The category breakdown was built from the PUTAWAY RULES instead of the
      real bin category in the data. Each bin was assigned to the first rule
      whose target pattern matched it, and bins matching NO rule were skipped
      entirely (`if (!owningRule) return;`).
        * No rule targets O2*, so every O2 bin was dropped.
        * The battery rule targets O3-B* / O3-C*, so the O5 battery bins
          matched nothing and were dropped.
      The result was a breakdown that only covered part of the zone and could
      never reconcile with the zone header.

    FIX:
      A. Capacity is now grouped by row.binCat (the BIN CATEGORY column of the
         uploaded data) - exactly the same field the heatmap blocks use - and
         mapped through mainMaterialCategory() to PACKING / BATTERY /
         RAW MATERIAL. Every bin of the zone is counted exactly once, so bins,
         pallets and empty always reconcile with the zone header.
      B. Demand is now charged to the bin category that will physically receive
         the pallet: the binCat of the suggested empty bin. When no slot is
         free, it falls back to the HU own main material category
         (new helper huMainCategory, PHONE/LCD/PCBA -> RAW MATERIAL).
      C. ensureZoneCategory(zoneName, label) now takes a category label instead
         of a putaway rule.
      D. Category rows are sorted in a fixed, predictable order:
         PACKING, BATTERY, RAW MATERIAL.

    EFFECT: every zone now lists all of its real bin categories, including
    categories with zero incoming demand (shown as "No GR HU routed").
